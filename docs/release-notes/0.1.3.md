**Frame Tidy now updates itself.** From this version on, when a new version is out, Frame Tidy shows a window with what's new and an **Install Update** button. It downloads, checks and installs the update, then reopens. You can also let it install updates by itself, or look any time with **Help › Check for Updates…**

Every update is checked twice before it's installed: it must be signed by the same developer as the copy you have, and carry Frame Tidy's own update signature.

## Download

**Frame-Tidy-0.1.3.dmg** works on any Mac with macOS 12.3 or later, Apple silicon or Intel. If you have 0.1.2 or earlier, install this one by hand once (replace the old app; your data is kept). After that, updates come to you.
